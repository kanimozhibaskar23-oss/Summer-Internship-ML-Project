\# Student Performance Prediction using Machine Learning



\## Project Overview



This project predicts student performance using Machine Learning.



The model uses three important factors:



\- Hours Studied

\- Attendance Percentage

\- Previous Marks



A Decision Tree Classifier is used to train the Machine Learning model and predict whether a student is likely to have good performance or needs improvement.



\## Technologies Used



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Decision Tree Classifier



\## Features



\- Takes student academic details as input

\- Trains a Machine Learning model

\- Calculates model accuracy

\- Predicts student performance

\- Gives a simple performance result



\## Input



The user enters:



1\. Study Hours

2\. Attendance Percentage

3\. Previous Marks



\## Output



The system displays:



\- Model Accuracy

\- Student Performance Prediction



Example:



```text

Student Performance Prediction

\--------------------------------
